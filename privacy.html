Privacy Policy

Last updated: 26 November 2026

About this policy

This policy describes how the internal application RS Inbox Helper, operated by TECH CONNECT LTD, handles data from Google accounts. The application is used only by our own team to read and manage the company's own mailboxes. It is not offered to the public.

Data we access

With the account owner's consent, the application uses the Gmail API to read messages, search mailboxes, create drafts and send messages that the account owner has approved.

How the data is used and stored

Mailbox data is processed only on the account owner's own computer, to help them read and answer their e-mail. Access tokens are stored locally on that computer. We do not copy mailbox content to our servers, and we do not sell, share or transfer it to third parties.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. Locally stored tokens are deleted when access is no longer needed.
